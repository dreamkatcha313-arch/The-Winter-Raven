## Proposed course structure
Six sequenced lessons per course, a 12–20 item expert-reviewed exam, proposed 80% passing threshold, retakes, accessibility, explicit source citations, and optional account linking. Existing five psychology subject files are introductory drafts and contain only seed questions; they do not qualify for reward issuance.

## Additional class tracks
- Druid Country: Childhood ADHD for parents, therapists and educators (development, evaluation, parent training, school support, coordination, case studies).
- Neuroscience: Serotonin and dopamine in learning (synapses, dopamine, serotonin, experiments, interpretation, ethical applications).

## Game synchronization
No rewards may be granted by client-side JavaScript alone. After assessment and server review, the Axiom backend will validate account, exam version, score, idempotency and mapped rewards. Fictional spells must never imply mental health conditions confer supernatural abilities.

## Publishing checklist
- [ ] Expand full lesson prose and activities
- [ ] Commission qualified content review
- [ ] Write and review complete question banks
- [ ] Build accessible class UI and assessment flow
- [ ] Implement authenticated server-side rewards
