# Winter Raven

An atmospheric, Norse-inspired educational archive centered on psychology and the human mind.

## Project files
- `index.html` — landing page and site shell
- `styles.css` — responsive visual design and snowfall effect
- `script.js` — hall directories, search, navigation, and educational article content
- `assets/winter-raven-background.png` — optional background image; not included yet

## The three halls
- Hugr's Hall — The Hall of the Mind (Diagnoses)
- The Weavers' Hall — The Hall of Syndromes (Syndromes)
- The Hall of Shadows — The Hall of Fears (Phobias)

## Run locally
Open `index.html` in a browser, or run `python -m http.server 8000` and visit `http://localhost:8000`.

## Important
This is educational information, not diagnosis or treatment. The sample articles are starting points, not exhaustive clinical references. Verify and expand all material and sources before publication. Medication treatments are intentionally outside the scope of this archive.

The raven background image is not included in this initial upload. Add it at `assets/winter-raven-background.png` when available; the site remains functional without it.
